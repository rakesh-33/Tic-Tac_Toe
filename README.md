# 🎮 Tic Tac Toe Game (C++)

A simple **console-based Tic Tac Toe game** built using **C++**, designed for **two players**.  
This project helped me practice **arrays, control flow, functions, and game logic** in C++.

---

## 📌 Features

- 🧑‍🤝‍🧑 Two-player gameplay (Player X vs Player O)
- 🧩 3×3 game board using a 2D array
- ❌⭕ Automatic turn switching
- ✅ Win detection (rows, columns, diagonals)
- 🤝 Draw detection
- 🖥️ Runs entirely in the terminal/console

---

## 🛠️ Tech Stack

- **Language:** C++
- **Concepts Used:**
  - Arrays (2D arrays)
  - Functions
  - Conditional statements
  - Loops
  - User input/output
